# Interview Questions

## Why Django?
It provides a structured backend framework and works well with REST APIs, ORM,
authentication and PostgreSQL.

## Why PostgreSQL?
The JD specifically mentions PostgreSQL/Oracle basics, SQL queries and connectivity.

## What is key rotation?
Replacing active cryptographic key material with a new version while maintaining
controlled lifecycle and auditability.

## Is this an HSM?
No. It is an HSM/KMS-adjacent simulation. Real production key operations should be
performed by approved HSM/KMS infrastructure.

## How do you troubleshoot a production incident?
Check impact, health endpoint, logs, database/network dependencies, recent changes,
mitigate, restore, collect evidence, document RCA and implement prevention.

## Why Nginx?
It demonstrates reverse proxy and application-server deployment concepts.

## What is SLA?
A defined service target for response/restoration/resolution associated with an incident.

## What is RCA?
Root Cause Analysis: identifying the technical cause and documenting corrective and
preventive actions.
